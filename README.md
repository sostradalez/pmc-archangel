# ЧВК «Архангел» — сайт

Одностраничный статический сайт подразделения «Архангел» (ролевой проект в сеттинге SCP).

- Один файл — `index.html`: без сборки, зависимостей и бэкенда.
- Шрифт JetBrains Mono подключается с Google Fonts.
- Реестр ролей и «архив» работают на чистом JS прямо в странице.

## Публикация

Сайт раздаётся через GitHub Pages из ветки `main`, каталог `/` (корень репозитория).
Адрес вида: `https://<логин>.github.io/<репозиторий>/`.

## Что стоит отредактировать

В секции «Связь и набор» (`id="contact"`) — три заглушки:

```html
<b class="edit">укажите ссылку-приглашение</b>
<b class="edit">укажите ссылку на канал</b>
<b class="edit">форма / заявка в Discord</b>
```

Замените их на реальные ссылки Discord / Telegram.

## Правки

1. Меняете `index.html` локально.
2. `git add . && git commit -m "описание правки"`
3. `git push`

GitHub Pages пересоберёт сайт автоматически за 30–60 секунд.

## Структура

```
index.html   — сама страница (CSS и JS внутри)
.nojekyll    — отключает обработку Jekyll на GitHub Pages
```
